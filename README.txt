My Expenses — iPhone PWA prototype

วิธีทดลอง:
1. อัปโหลดโฟลเดอร์นี้ขึ้นบริการ static hosting ที่รองรับ HTTPS
2. เปิด URL ด้วย Safari บน iPhone
3. กด Share > Add to Home Screen
4. ข้อมูลรายจ่ายเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น

ฟังก์ชัน:
- รายจ่ายตามเดือน
- เงินสด / บัตรเครดิต / โอน
- บัตรเครดิตหลายใบ
- หมวดหมู่
- โน้ต
- ค้นหาจากโน้ต/หมวด/วิธีจ่าย
- สรุปตามหมวด
